1导出你的 git log

在你的仓库目录下跑一条命令，把输出整段粘过来。多个仓库的输出直接粘在一起就行。


      

        
        
        
        
      


      

        不知道仓库目录在哪 / 不会用命令行？点这里 →
        

          
命令要在你的项目文件夹里执行——也就是那个里面有 .git 文件夹的目录。三步：

          
    
            
  1. 打开终端：按 Win 键，输入 powershell 回车（Mac 是「终端」，Linux 是 Ctrl+Alt+T）
    2. 
            
  2. 找到你的项目：最省事的办法是在终端里直接问，把下面这条粘进去（Windows / PowerShell 用），它会把你电脑上所有 git 仓库列出来：
              
    Get-ChildItem -Path "$env:USERPROFILE","D:\" -Directory -Recurse -Depth 3 -Force -ErrorAction SilentlyContinue | Where-Object { Test-Path (Join-Path $_.FullName '.git') } | Select-Object -ExpandProperty FullName
    
            
    3. 
            
  3. 进目录再跑：把上一步找到的路径套进下面这句（路径里有空格或中文，一定要加引号），再粘贴上面那条 git log 命令：
              
    cd "D:\你的项目目录"
    
            
    4. 
          

          
Mac / Linux 的找法：find ~ -name .git -type d -maxdepth 4 2>/dev/null

          
小技巧：也可以在项目文件夹的地址栏里直接输入 powershell 回车，终端就会自动开在这个文件夹里，连 cd 都省了。

          
贴不进去也没关系——在项目文件夹里按住 Shift + 鼠标右键 →「在此处打开 PowerShell 窗口」，然后右键终端全选复制就行。
