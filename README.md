# 代码年轮 · Code Tree Rings

把你的 `git log` 变成一张 1024 年度海报。

**单文件 · 零依赖 · 双击即开 · 离线可用 · 数据全程不离开浏览器。**

为 TRAE 社区「玩法二｜展示：TRAE 1024 作品秀」而建。

---

## 一、它是什么

一个纯前端网页。粘贴一段 `git log` 输出，它在本地解析，然后画出一张可以收藏、可以发群的年度海报：

- **24 小时提交钟面** —— 圆环上每一根刺是一个小时，越长提交越多
- **星期分布** —— 一周里哪天最能写
- **段位徽章** —— 2⁰ → 2¹⁰ 共 11 级，满级就是 **1024**
- **Builder 指数** —— 0–100 的健康度综合分
- **commit message 病历本** —— 敷衍指数、病情分级、最该被枪毙的那条 commit
- **导出 PNG** —— 2400×3200，2 倍分辨率

海报只由一张 Canvas 绘制，页面里看到的就是导出结果，不存在「所见非所得」。

## 二、30 秒上手

1. 双击打开 `index.html`（无需服务器、无需 npm install）
2. 点「**复制命令**」，在自己的仓库目录粘贴执行；或者直接点「**载入示例年度**」
3. 把输出粘进文本框，点「**生成我的年轮**」
4. 点「**导出 PNG**」，保存，发群

**没有 git？** 展开「手动填数模式」，填提交数 / 活跃天数 / 连续天数 / 最常时段即可出图。

## 三、支持哪些 git log 格式

| 格式 | 说明 |
|---|---|
| `git log --pretty=format:'%h&#124;%ad&#124;%an&#124;%s'` + `--date=format:'%Y-%m-%d %H:%M:%S'` | 主路，含时间与作者 |
| 同上 + `--date=short` | 仅日期 |
| `git log --oneline` | 极简，日期归入「未知日期」 |
| `git log` 默认输出（直接复制终端内容） | 自动识别 `commit / Author: / Date:` |
| 以上任意 + `--numstat` | 统计增删行数与触碰文件 |

分隔符容忍 `|` `,` `;` `Tab`；subject 里含分隔符时保留；CRLF、二进制文件（`-`）、重命名（`a => b`）、注释行、空行全部容错。多个仓库的输出直接粘在一起即可。

上限 20000 条，超出截断并提示。

## 四、技术实现

- **单文件 HTML**，无框架、无 CDN、无后端、无第三方库，`file://` 下完整可用
- **解析器**：按行状态机，依次尝试「git 默认格式 → numstat → 自定义 format 头 → 缩进消息体 → oneline → 续行兜底」
- **统计层**：24 小时 / 星期 / 动词 / 文件四类分桶，最长连续提交用「排序日期 + 相邻差 1 天」线性扫描
- **渲染层**：Canvas 2D，按 `devicePixelRatio` 缩放；海报是唯一真相源
- **导出**：离屏 Canvas `scale(2,2)` 重绘 + `toBlob`，产出 2400×3200 PNG
- **隐私**：全部计算在浏览器内，没有任何网络请求；排行榜存 `localStorage`

### 统计口径（可复核）

- **活跃天数** = 去重日期数
- **跨度** = 首末日期差 + 1 天
- **深夜指数** = 0–6 点提交数 / 有日期的提交数
- **周末战士指数** = 周六 + 周日提交数 / 有日期的提交数
- **最长连续提交** = 相邻日期相差恰为 1 天的最长链
- **段位** `level = clamp(floor(log2(N)), 0, 10)`，阈值即 2⁰…2¹⁰
- **Builder 指数** = `0.4×活跃天数占比 + 0.2×min(连续/30,1) + 0.2×(1−深夜占比) + 0.2×(1−敷衍指数/100)`，取整到 0–100
- **敷衍指数** = `clamp(round(100 × (1 − e^(−density/2.2))), 0, 100)`，其中 `density = Σ(规则权重×命中次数) / 消息数`

### 敷衍指数校准值

| 输入 | 得分 |
|---|---|
| 全部 `feat: …` / `fix(api): …` 等 conventional 提交 | 0 |
| 全部 `fix` | ≈ 60 |
| 全部「最终版」 | ≈ 84 |

病情分级：0–19 健康 / 20–39 早期 / 40–59 中期 / 60–79 晚期 / 80–100 已列入 1024 纪念册。

## 五、内置自检

地址栏加上 `?selftest=1` 打开，例如：

```
index.html?selftest=1
```

覆盖解析器（三种自定义精度、默认格式、oneline、numstat、二进制、重命名、CRLF、注释行、空输入、20000 条截断）、统计口径、段位 11 档边界、Builder 指数两端、病历规则逐条触发、示例数据确定性与规模、三种配色渲染、零数据与满级数据渲染、离屏画布像素非空、`toBlob` 环境可用性、时间过滤。共 **40** 条。

- **解析器**：git log 三种时间精度的格式兼容、git 默认格式的 `commit / Author: / Date:` 状态机、numstat 含二进制与重命名的归一化、分隔符容忍与 subject 切分策略
